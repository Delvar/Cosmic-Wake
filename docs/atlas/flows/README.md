# Flows

Flow docs explain user journeys across multiple files.

Create one flow document per important user journey.

Examples:

- login.md
- search.md
- checkout.md
- profile-update.md
- dashboard-load.md

Each flow should explain:

1. What the user is trying to do.
2. What files are involved.
3. What state or API calls are involved.
4. What can go wrong.
5. What tests cover the flow.
